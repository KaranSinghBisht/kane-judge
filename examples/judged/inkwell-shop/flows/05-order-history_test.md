# Find a placed order under Account → Orders

## Place a demo order
Add the first product in the catalogue to the cart, go to checkout and pay with obvious test data: the name "Kane Judge test", the email test+kanejudge@example.com, the test card number 4242 4242 4242 4242, expiry 12/30 and CVC 123. Verify the page visibly shows an order number (and store that order number as "order_number").

## Open the order history
Open Account, then Orders. Verify the Orders page visibly lists an order with the order number you stored as "order_number".

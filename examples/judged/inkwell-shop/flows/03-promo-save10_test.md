# Apply the SAVE10 promo code at checkout

## Open checkout with an item
Add any one product to the cart and go to the checkout page. Verify the order summary visibly shows a Subtotal, Shipping and a Total.

## Apply the promo code
Enter the promo code SAVE10 and apply it. Verify the order summary visibly shows a Discount greater than $0.00.

## Check the new total
Look at the order summary again. Verify it still visibly shows a Total, and that the Total equals the Subtotal minus the Discount plus the $5.00 shipping.

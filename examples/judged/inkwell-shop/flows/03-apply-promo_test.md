# Apply SAVE10 at checkout

## Put a product in the cart and open checkout
Add the first product in the catalogue to the cart, then open the cart and go to checkout. Verify the checkout page visibly shows an order summary with a Subtotal.

## Apply the promo code
Enter the promo code SAVE10 in the promo code field and apply it. Verify the order summary visibly shows a discount line with a discount amount greater than $0.

## Check the new total
Look at the order summary again. Verify the order summary visibly shows a Total, and that the Total equals the Subtotal minus the Discount plus the shipping.

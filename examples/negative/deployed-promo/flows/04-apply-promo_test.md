# Apply the SAVE10 promo code

## Add a product to the cart
Add the "Brass Pen" to the cart. Verify the cart badge in the header visibly shows 1.

## Open the checkout page
Open the cart from the header to reach the checkout page. Verify the "Order summary" visibly shows a Subtotal of $42.00.

## Apply the promo code
Type the promo code SAVE10 into the "Promo code" field and press Apply. Verify the "Order summary" visibly shows a Discount line with an amount above $0.00, and a Total equal to the Subtotal minus the Discount plus $5.00 shipping.
